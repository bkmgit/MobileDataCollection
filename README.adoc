= README

HTML slides can be produced with https://asciidoctor.org/[asciidoctor]. Use

[source,bash]
---
asciidoctor MobileDataCollection.adoc
---

A pdf version can be generated with
https://docs.asciidoctor.org/pdf-converter/latest/[asciidoctor-pdf]. Use

[source,bash]
---
asciidoctor-pdf -a pdf-theme=tp -a pdf-themesdir=resources/themes \
-a pdf-fontsdir=resources/IntelOneMonoTTFFonts MobileDataCollection.adoc
---
